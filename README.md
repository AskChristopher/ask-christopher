# Ask Christopher

> Building AI systems that help people learn, create, and solve problems.

---

## About

**Ask Christopher** is an AI-powered learning and productivity platform created by Christopher Mathews.

The long-term vision is to build an intelligent assistant that combines conversational AI, educational design, document understanding, and automation into a single experience. Rather than simply answering questions, Ask Christopher is being designed to help people learn by building, create useful artifacts, and become more capable with AI.

This repository documents the development of that system in public.

---

## Who This Project Helps

Ask Christopher is being built for:

- Students learning technical skills
- Professionals adopting AI in their work
- Instructional designers
- Educators and trainers
- Small businesses
- Lifelong learners
- Anyone who wants AI that teaches—not just answers
